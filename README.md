## 📌 Featured Project

### 📊 [Mutual Fund Lens](https://github.com/anushkumar701/mutual-fund-lens)

> A full-stack analytical web platform built to process, evaluate, and visualize mutual fund performance data.

- **Architecture:** MVC (Model-View-Controller) design pattern using Java Servlets & JDBC.
- **Backend & Database:** Direct relational data persistence with MySQL, managing structured queries and dynamic data extraction.
- **User Interface:** Structured, responsive design engineered with semantic HTML5 and custom CSS3.
- **Key Features:** Automated metric calculation, data filtering, and portfolio performance tracking.
